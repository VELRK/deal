================================================================================
WHATSAPP UTILITY TEMPLATES — Askeva / Syncr / Meta
================================================================================
Category : UTILITY
Language : en
Create EACH template with the EXACT template name shown.
Configured in: application/config/whatsapp.php

Variables (either style works; app mode=auto tries both):
  Positional: {{1}} = customer name, {{2}} = order number
  Named:      {{Customername}}, {{OrderName}}

Sample for approval:
  {{1}} / Customername = Ahmad
  {{2}} / OrderName    = ORD-12345

App sends positional first, then named if Syncr rejects.
