Create EACH template with the EXACT template name shown.
Configured in: application/config/whatsapp.php

Named variables (match Askeva exactly):
  {{Customername}} = Customer name
  {{OrderName}}    = Order number

Sample for approval:
  Customername = Ahmad
  OrderName    = ORD-12345

App sends:
  parameter_name "Customername" + "OrderName"
