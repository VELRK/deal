2DEAL.MY — UPLOAD THIS ZIP TO cPanel
====================================

1) Extract ALL files into public_html (document root of 2deal.my)
   - You should see index.php, .htaccess, application/, system/, frontend/, assets/ at the TOP of public_html
   - Do NOT leave them inside a "deal1" or "2deal-my-deploy" subfolder

2) Database (required)
   - cPanel → MySQL Databases → create database + user + All Privileges
   - phpMyAdmin → Import your SQL dump
   - Edit: application/config/database.php
     OR rename application/config/database.php.server → database.php
     and fill CHANGE_DB_USER / CHANGE_DB_PASSWORD / CHANGE_DB_NAME

3) Folders permissions (File Manager)
   - uploads/                → 755 or 775
   - application/cache/      → 755 or 775
   - application/logs/       → 755 or 775

4) PHP
   - MultiPHP: 8.0+ with mysqli, mbstring, curl, openssl, gd/fileinfo

5) SSL
   - AutoSSL for 2deal.my + Force HTTPS

6) Test
   - https://2deal.my/
   - https://2deal.my/admin
   - https://2deal.my/shopkart-api/ (needs auth for most routes)

Notes
- Frontend already built for https://2deal.my (API = /shopkart-api, assets = /frontend/)
- base_url auto-detects on the server (no localhost /deal path)
- This package excludes: .git, node_modules, local DB passwords may still be in database.php — REPLACE them on server

If admin product Save returns HTTP 403
1) Check the page text: if it says "Access denied: this product belongs to another vendor" → log in as main Admin (not Vendor) / exit vendor mode.
2) If Apache shows plain "403 Forbidden" (no app message) → cPanel ModSecurity is blocking the POST (common with image upload + long description). Temporarily disable ModSecurity for the domain, or upload smaller JPG/PNG and rename files (no spaces), then re-enable.
3) Prefer image names without spaces: Spiritual_Collection_1.jpg not "Spiritual Collection 1.jpg"
